# Knovatrix 刷題站

可依學段、科目、單元與題型建立專屬練習任務的純前端題庫工作台。

## 主要頁面

- 總覽：題庫規模、學段入口與練習紀錄摘要。
- 題庫：只顯示已完成題目化且能自動批改的題目。
- 建立任務：依「學段 → 科目 → 單元 → 題型／題數」逐步建立練習。
- 練習紀錄：作答數、答對數與正確率。

## 題庫收錄原則

外部 PDF 需完成「題面、答案、題型、解說」結構化後才會加入互動題庫。沒有答案、屬於多重選擇、計算證明或尚待核對的資料不會先顯示為可作答題目。

## A-ADS 廣告設定

在 `ads.js` 的 `AADS_UNITS` 填入 A-ADS 後台建立的四個 Ad Unit ID：

- `desktop-left`：160 x 600
- `desktop-right`：160 x 600
- `mobile-top`：320 x 100
- `mobile-bottom`：320 x 100

寬於 1180px 時只顯示左右側欄；1180px 以下時只顯示內容上方與題目下方。廣告不使用固定浮動，不會遮住作答控制。
